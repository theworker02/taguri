# taguri

Tag encode/decode helpers for uri payloads in pipelines.

**Site:** https://theworker02.github.io/taguri/

## Install / run

```bash
git clone https://github.com/theworker02/taguri.git
cd taguri
node src/cli.js
node --test
```
